# First steps

Super is the Windows key. Five keys get you everywhere:

| Keys | What it does |
| --- | --- |
| Super + Space | find and open an app |
| Super + Alt + Space | the menu: everything else |
| Super + K | every key binding |
| Super + Return | a terminal |
| Super + Ctrl + T | pick a theme |

## Make it yours

1. Super + Ctrl + T: pick a theme. Arrows move, Enter applies.
2. Menu › Style › Background: pick a wallpaper from the theme's own.
3. Menu › Setup › Wi-Fi: connect, if you haven't yet.

## Find your way

- The menu searches every page as you type: try `wifi`, `theme` or `shut`.
- `hyprtrixie guide` brings you back here; Menu › Learn › Welcome shows the welcome screen again.
- The setup menu (`sudo hyprtrixie`) changes the bigger choices: apps, scale, idle times, the window style.
