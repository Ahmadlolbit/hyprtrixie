# Themes and backgrounds

- Super + Ctrl + T: the theme picker. Arrows or the wheel move, typing filters, Enter applies, Escape leaves.
- Menu › Style › Background: the same picker with the theme's wallpapers. Menu › Style › Next background flips to the next one.

Everything follows the theme: the windows, the bar, the terminal, notifications, the lock screen, the login screen, and the boot splash and boot menu.

## Wallpapers

Set any picture as the wallpaper from a terminal:

```bash
hyprtrixie-background ~/Pictures/mountains.jpg
hyprtrixie-background next
```
