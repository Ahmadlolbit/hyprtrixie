# Windows and workspaces

New windows tile: they share the screen instead of overlapping.

| Keys | What it does |
| --- | --- |
| Super + arrows | move the focus |
| Super + Shift + arrows | move the window |
| Super + Ctrl + arrows | resize the window |
| Super + drag | move with the left button, resize with the right |
| Super + Q | close the window |
| Super + F | full screen |
| Super + T | float the window, or tile it again |
| Super + J | split the other way |
| Alt + Tab | cycle the windows |

## Workspaces

| Keys | What it does |
| --- | --- |
| Super + 1 … 0 | go to workspace 1 to 10 |
| Super + Shift + 1 … 0 | send the window there |
| Super + Tab, Super + scroll | the next or previous workspace |
| Super + S | show or hide the scratchpad |
| Super + Alt + S | send the window to the scratchpad |

The number keys go by position, so they work with any keyboard layout.
