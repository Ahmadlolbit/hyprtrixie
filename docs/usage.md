# Using hyprtrixie

## The setup menu

`sudo ./hyprtrixie` opens it. After the first install, `hyprtrixie` is a command, so `sudo hyprtrixie` works from any folder.

- Arrow keys move, Enter opens a section or picks a value, Esc goes back.
- In a terminal at least 130 columns wide, every setting has a short explanation beside it. Changing a setting shows its explanation under its name, whatever the width.
- Applications lists the categories (browsers, office, games…); each opens its own list of apps.
- In the app and tool lists, Space ticks or unticks an item, and Enter confirms the list.
- The bottom of the menu has **Save configuration**, **Load configuration**, **Install** and **Exit**.
- Changing the profile asks whether to reset the app and tool lists to that profile.

Choices are saved in `/etc/hyprtrixie/hyprtrixie.conf`. It's a plain shell file, one `NAME=value` per line.

| Command | What it does |
| --- | --- |
| `sudo ./hyprtrixie config show` | every option with its label and value |
| `sudo ./hyprtrixie config path` | where the file is |
| `sudo ./hyprtrixie config edit` | open it in your editor |
| `sudo ./hyprtrixie config reset` | back to the defaults |

## Running the setup

| Command | What it does |
| --- | --- |
| `sudo ./hyprtrixie install` | runs every module with the saved choices |
| `--yes` | asks nothing |
| `--config FILE` | uses another configuration file |
| `--only 12,13` / `--skip 10,11` | runs only some modules, or leaves some out |
| `--on-failure ask\|halt\|continue` | what happens when a step fails |
| `sudo ./hyprtrixie verify` | runs every check again and rewrites `~/runbook-report.md` |
| `./hyprtrixie modules` | each module and how it last ended |
| `sudo ./hyprtrixie collect` | `~/hyprtrixie-collect-<date>-<time>.tar.gz` with logs, the report and system details |

While it runs, each module's line says where you are ("12  Desktop session · 7 of 17"), and the running step's last three output lines show dimmed under it.

When a step fails, you see its last lines and choose:
- **Retry**: runs the step again.
- **Skip**: moves on, and the report lists the step as skipped.
- **Continue**: moves on, and the report lists the step as failed.
- **Halt**: stops the run.
- **Show log**: opens the step's whole output, then asks again.

At the end, a box sums up the run: how long it took, the steps and checks that passed, were skipped or failed, the packages it installed, the files it updated or kept because you edited them, and what to do next.

Everything is logged in `/var/log/hyprtrixie/` and `~/runbook-logs/`.

### Running it again

Running the setup again is safe, for example after changing an option:
- Steps that are already done are checked, not redone.
- Downloads are pinned to a version and a checksum, and only fetched again when the pin changes.
- Files you edited are kept. When hyprtrixie has a newer version of one, it writes it next to yours as `<file>.hyprtrixie-new` and tells you. Compare the two and merge what you want.
- A file hyprtrixie replaces outright, such as Hyprland's autogenerated config or the installer's network file, is kept as `<file>.hyprtrixie-old`.

- To change the layout, run `sudo dpkg-reconfigure keyboard-configuration`, then log out and back in.

Super+Alt+Space opens the menu.

- Arrows or the mouse move, Enter or a click opens, Backspace or Left goes back, Escape closes.
- Typing searches every page at once, for example `wifi` finds Toggle › Wi-Fi and Setup › Wi-Fi. On a list page (Apps, Install, Remove) it searches that list first.

| Entry | What's in it |
| --- | --- |
| Apps | every installed app |
| Learn | Guide (in the terminal), Keys (the key sheet), Welcome |
| Capture | screenshot of a region, a window or the screen |
| Toggle | screensaver, stay awake, stay awake for a while, night light, do not disturb, Wi-Fi, Bluetooth; a dot shows which are on |
| Focus | a focus timer of 25 or 50 minutes, or Stop |
| Style | Theme and Background open the full-screen pickers; Next background |
| Setup | Wi-Fi, Audio, Brightness and Power open the bar's popups; Bluetooth opens Blueman |
| Install | apps from the catalogue, or any Debian package |

- Super+Ctrl+T opens the theme picker, and Super+Escape the System page.

### Your own entries

The menu is described in `/usr/share/hyprtrixie/shell/menu.json`. Your own entries go in `~/.config/hyprtrixie/menu.json`, in the same shape. An id that's already in the menu changes only the fields you give. Changes show the next time the menu opens.

```json
{
  "work": { "glyph": "󰃖", "label": "Work" },
  "work.vpn": { "glyph": "󰖂", "label": "Office VPN", "action": "nmcli connection up office" },
  "system.shutdown": { "label": "Power off" }
}
```

- The id's dots make the pages: `work.vpn` sits in `work`, which sits on the first page.
- `action` is a shell command. An entry with `state` too is a toggle: `state` is a command that succeeds when it's on.
- `keywords` (a list of words) helps search find it.
- Glyphs are Nerd Font icons; pick one at nerdfonts.com/cheat-sheet.

## Apps

The apps come from a catalogue of about sixty, in ten categories. The setup menu's Applications ticks the defaults for your profile; the rest are offered.

```bash
hyprtrixie app list                 # every app by category; * marks the installed ones
hyprtrixie app list available       # the ones you can still install
sudo hyprtrixie app install gimp
sudo hyprtrixie app remove gimp
```

- Installing ticks the app in your configuration, and removing unticks it, so the next run of the setup agrees.
- Each app comes from Debian or backports when it's there, otherwise from the vendor's repository (through extrepo) or a pinned download.
- Removing an app also turns its vendor repository off when nothing else uses it.
- Menu › Install and Menu › Remove do the same in a floating terminal. **Any Debian package** there searches every package with fzf.
- Images open in imv, PDFs in Evince (Okular when Evince isn't ticked), videos and music in VLC, archives in Ark. hyprtrixie sets these once; your own choices afterwards stay.

## Updating

```bash
hyprtrixie update
```

It updates everything, in this order, and stops if something fails:

1. A snapshot, "before hyprtrixie update", to go back to.
2. Debian's packages.
3. Flatpak apps, mise's tools and Rust, when you have them.
4. hyprtrixie: it pulls the newest version into the folder you installed from, shows what changed, then runs the setup.

- `hyprtrixie update system`, `apps` or `hyprtrixie` run one part.
- The notes on what changed end the setup's summary, and the next login shows a notification with a **Read** button.
- `hyprtrixie changes` shows the last notes again, and so does Menu › Update › What changed.
- Menu › Update has Everything, hyprtrixie, Debian packages, firmware and What changed; the bar's update badge runs Everything.

## Checking the system

`sudo hyprtrixie doctor` checks the system in plain words:

- the desktop's programs (the bar, the wallpaper, notifications, the launcher, idle) and failed services
- snapshots: the timers, and when the newest one was taken
- free disk space
- the battery's health, firmware errors since boot, and waiting updates
- hyprtrixie's own files: missing ones, `.hyprtrixie-new` files waiting for you, and whether the setup last ran from the folder's version

Each problem comes with what to do. The safe fixes (start a program again, restart a failed service, turn the snapshot timers on, free space) are offered one at a time, and nothing happens unless you say yes. Menu › System › Check the system runs it too.

## Learning the desktop

- **The welcome screen** shows once, a moment after the first login: the five keys that get you everywhere, and buttons for a theme, a background and the guide. Menu › Learn › Welcome brings it back.
- **The key sheet**: Super+K, see Keys.
- **The guide**: `hyprtrixie guide`, or Menu › Learn › Guide, reads the guide's pages in the terminal.
- **Tips**: a short tip shows under the prompt in new terminals, one on the welcome screen, and a notification at most once a day. Each has its own switch in the setup menu's Look and feel. Your own tips go in `~/.config/hyprtrixie/tips.txt`, one per line.

## Screenshots

`hyprtrixie-screenshot region|window|screen` is behind the Print keys. It does three things:
- saves to `~/Pictures/Screenshots`
- copies to the clipboard
- shows a notification. Click **Edit** on it to annotate the screenshot in swappy.

## Lock and idle

With the default options:
1. At 3 minutes idle, the screensaver starts on every monitor. Any key or mouse movement ends it.
2. At 4:30, the screen dims and the keyboard backlight turns off.
3. At 5 minutes, it locks.
4. 30 seconds later, the screen turns off.
5. At 30 minutes, the laptop suspends.

- Change the minutes in the installer's menu (System). 0 turns the screensaver, locking or suspend off. The screensaver only starts when it comes before the lock.
- The **awake** toggle in the bar stops idle locking until you turn it off again.
- Menu › Toggle › Screensaver turns the screensaver off or on for your account. `hyprtrixie-screensaver status` says which, and `hyprtrixie-screensaver start` shows it now.
- The screensaver animates the text in `/usr/share/hyprtrixie/screensaver.txt`. Put your own in `~/.config/hyprtrixie/screensaver.txt`.

## Themes

- Super+Ctrl+T (or Style → Theme in the menu) dims the screen behind a row of theme previews, starting at the current theme:
  - Left/Right or the mouse wheel move, and typing filters by name
  - Enter, or a click on the selected preview, applies
  - Escape, or a click outside, closes without changing anything
- Running apps change straight away. The new theme's first wallpaper is used. Applying the same theme again keeps the wallpaper you have.
- The login screen follows at once. The boot splash and the boot menu follow too; the boot image is rebuilt in the background, which takes about a minute.
- Running the installer again keeps the theme you picked. Changing the theme in the installer's menu applies the new one.
- Change the wallpaper with Style → Background in the menu (the same picker, with the theme's backgrounds), or from a terminal:

  ```bash
  hyprtrixie-background --list
  hyprtrixie-background next
  hyprtrixie-background ~/Pictures/mountains.jpg
  ```

### The boot and the login screen

- The boot shows a splash with the hyprtrixie logo in the theme's colours, and asks for the disk password under it. Esc shows the boot messages instead.
- The boot menu is hidden: press Esc right after the laptop's logo to see it, with the snapshots. It's in the theme's colours too.
- The login screen matches the lock screen: your wallpaper blurred, the clock and the date, the password field in the theme's colours. Click your name to pick another account.
- All three follow theme and wallpaper switches by themselves.
- Turn them off in the setup menu's Look and feel: **Boot splash**, **Boot menu in the theme**.
- **Console colours and font** (off by default) paints the text consoles (Ctrl+Alt+F3 and so on) in the theme's colours, with a larger font.

- The sun is worked out for your time zone's main city, without the internet; set `location` if you're far from it.
- The weather comes from Open-Meteo for the same place, every 30 minutes. Without the internet for three hours, it hides until it can update again.

## Changing the Hyprland config

`~/.config/hypr/hyprland.lua` starts with one line that loads the hyprtrixie defaults. Add your own settings below it; anything you add wins. Hyprland reloads when you save. Example:

```lua
dofile("/usr/share/hyprtrixie/hypr/hyprtrixie.lua")

hl.bind("SUPER + G", hl.dsp.exec_cmd("gimp"), { description = "GIMP" })
```

The defaults are split into modules in `/usr/share/hyprtrixie/hypr/`:
- `envs.lua`, `looknfeel.lua`, `input.lua`, `windows.lua`, `autostart.lua` and `bindings.lua`
- the two window styles, `style-sharp.lua` and `style-soft.lua`

To replace one for every account on the machine, put a file with the same name in `/etc/hyprtrixie/hypr/`. That folder also holds `options.lua`, which the menu writes (scale, scrolling, tap to click, animations, window style).

Check a change without logging out: `Hyprland --verify-config`.

## The bar

- The bar's settings live in `~/.config/hyprtrixie/shell.json`. They are applied as soon as you save.
- Anything you leave out falls back to `/etc/hyprtrixie/shell.json` (written by the menu), then to the defaults.

```json
{
  "bar": {
    "position": "bottom",
    "clock": "12h",
    "left": ["workspaces", "window"],
    "center": ["clock"],
    "right": ["indicators", "tray", "cpu", "memory", "network", "audio", "brightness", "power-profile", "battery"]
  }
}
```

Widgets:

| Widget | What it shows, and what you can do with it |
| --- | --- |
| `workspaces` | workspaces on that monitor |
| `window` | the focused window's title |
| `media` | what's playing, in the browser or any player. Click for the cover, previous, pause and next. Middle-click to pause, scroll to skip |
| `clock` | time and date. Click for a calendar |
| `focus` | the focus timer, while one runs. Click to start over or stop |
| `cpu`, `memory` | CPU and memory use |
| `temperature` | the CPU temperature, orange from 80 °C and red from 90 °C. Click for the other temperatures and the fans |
| `network` | network status. Click for Wi-Fi: turn it on or off, pick a network, type a password, forget a network |
| `audio` | volume. Click for the speakers, the microphone, their devices, and each app playing sound with its own slider and mute. Scroll to change the volume, right-click to mute |
| `bluetooth` | Bluetooth, off, on or connected. Click for the switch, your devices with their battery (click to connect or disconnect, Forget on hover) and Scan to pair new ones |
| `brightness` | screen brightness. Click for sliders, the keyboard backlight too when there is one. Scroll to change it |
| `battery` | battery level and charging. Click for time left, charge rate, battery health and the power mode |
| `power-profile` | the power profile. Click to cycle |
| `privacy` | shows when an app uses the microphone or the camera, or shares the screen. Click to see which |
| `indicators` | the coffee cup and the muted-microphone warning. Click the cup to stay awake until you click again; right-click for 30 minutes, 1 hour or 2 hours |
| `tray` | the system tray |
| `updates` | how many updates are waiting. Click to update in a terminal |
| `snapshots` | the newest snapshot. Turns red when the timeline snapshots have stopped; the popup offers Check the system |

### Layouts

`"preset"` in the bar settings picks a layout; Menu › Style › Bar layout or `hyprtrixie-look bar floating` change it:

| Preset | What it looks like |
| --- | --- |
| `full` | across the whole top (or bottom) |
| `floating` | a rounded bar with a gap around it |
| `minimal` | workspaces, the clock and the status icons |
| `vertical` | a narrow bar down the left side; popups open beside it |

Widget lists you set yourself win over the preset's.

- Popups close with Escape or a click anywhere else, and only one is open at a time.
- Their corners follow the window style. Set `"style": "soft"` or `"sharp"` in your `shell.json` to choose them for the bar alone.
- A key or script can open one: `qs -p /usr/share/hyprtrixie/shell ipc call popup toggle wifi` (also `audio`, `bluetooth`, `brightness`, `battery`, `calendar`, `media`, `weather`, `snapshots`, `notifications`, `privacy`, `temperature`, `awake`, `focus`).

## Notifications

- mako shows them.
- Your `~/.config/mako/config` includes the hyprtrixie defaults and the theme colours. Add your own settings below those lines.
- Menu › Toggle › Do not disturb hides them until you turn it off; they still arrive, and the bell in the bar lists them.
- The bell's popup lists the recent ones, newest first. Clear empties the list, Show the last one brings the last one back on screen, and the switch is do not disturb.
- Quiet hours turn do not disturb on and off by themselves, 22:00 to 07:00 by default: Menu › Toggle › Quiet hours, or `hyprtrixie-look quiet-hours`.

## Focus timer

Menu › Focus starts 25 or 50 minutes: the bar counts down after the clock and notifications are held. At the end a chime and a notification say to take a break, and a 5-minute break counts down. Click the timer to start over or stop.

- The timer has its own switch: it never changes do not disturb or quiet hours.
- A script or a key can start it: `qs -p /usr/share/hyprtrixie/shell ipc call focus start 25`, and `focus stop`.

## Staying awake

- Click the coffee cup in the bar, or Menu › Toggle › Stay awake: the screen doesn't lock or sleep until you turn it off.
- For a while: right-click the cup, or Menu › Toggle › Stay awake for: 30 minutes, 1 hour or 2 hours. The cup shows the minutes left.
- A script or a key can do it too: `qs -p /usr/share/hyprtrixie/shell ipc call awake minutes 60`, also `on`, `off` and `toggle`.

## Containers

- `engine-switch docker`: Docker CE answers to `docker`.
- `engine-switch podman`: `docker` commands are passed to Podman.
- `engine-switch status`: shows which engine is in use.

Docker publishes ports on localhost only unless you chose "all" in the menu. Docker and Podman storage is kept out of the system snapshots.

## Snapshots and rollback

- **When snapshots are taken:** snapper takes timeline snapshots of the system and keeps 7 daily, 4 weekly and 1 monthly by default. It also takes one before and after every apt run, keeping the last 10. The first snapshot is "hyprtrixie: before setup".
- **What they cover:** only the system. Your files in `/home` and the logs in `/var/log` are not rolled back.
- **List them:** `snapper list` (no sudo needed for admin accounts). The bar shows the newest one's time, and turns red if snapshots have stopped.
- **To go back:**
  1. Reboot and pick the snapshot from the snapshots submenu in the boot menu. The system boots from it read-only.
  2. If it's the one you want, run `sudo snapper-rollback <number>`.
  3. Reboot.

## Backups

`~/bin/restic-backup` backs up your home folder with restic:

```bash
restic-backup init /media/$USER/usb-drive/backups    # once: where backups go
restic-backup                                         # back up now
restic-backup list
restic-backup restore <id> ~/restored
restic-backup mount ~/backup-browser
restic-backup check
restic-backup prune                                   # keep 7 daily, 4 weekly, 6 monthly
```

- The password is generated and stored in `~/.config/restic-backup/password`. Keep a copy somewhere safe: without it the backups can't be read.
- Extra patterns to leave out go in `~/.config/restic-backup/excludes`, one per line.

## Security and network

| Option | What it means |
| --- | --- |
| Firewall | UFW blocks incoming connections. To open a port: `sudo ufw allow 8080/tcp` |
| Automatic security updates | unattended-upgrades installs Debian security updates in the background |
| SSH: client | the SSH server, if installed, is disabled at boot |
| SSH: leave | leaves `sshd` as it is |
| NetworkManager | Wi-Fi set up in the Debian installer moves to NetworkManager, so the bar and the tray can manage it. The old `/etc/network/interfaces` is kept as `/etc/network/interfaces.hyprtrixie-old` |

## Power

- `power-profiles-daemon` provides the power-saver, balanced and performance profiles. Switch with the bar widget or `powerprofilesctl set balanced`.
- On Intel machines, `thermald` also runs.
